# Contribution policy

Vecretary Memory accepts bug reports, feature requests, and security reports during the
initial alpha release. External code contributions and pull requests are not
accepted at this stage. Please describe issues rather than submitting patches.
Reports should use synthetic data, not real memories, credentials, or private
configuration. See [SECURITY.md](SECURITY.md) for sensitive reports.

This is a project intake policy, not an additional license condition. The plain
[MPL-2.0 license](LICENSE) governs use, modification, and redistribution. This
policy grants no ownership or licensing claim over outside submissions. Future
contribution arrangements will be announced before external code is accepted.
